TradeLens — Mac setup for your separate MT5 account

This package contains software only. It contains no Richard trades, database, passwords or device tokens. Read-only MT5 indicator + local Python importer/uploader. No broker orders. No automatic background service is installed. Each --send is one upload.

1. AirDrop this ZIP to your Mac and extract it. Keep the extracted folder together.
2. Sign in to https://tradelens.chardee.dev using YOUR OWN TradeLens account, not Richard's. My devices → create a token for your Mac. Keep it private; do not share it in chat.
3. Open MT5 and sign in to YOUR OWN Exness demo account. This version requires USD, hedging mode and a UTC+0 broker server. Live journaling requires the explicit opt-in steps below. Netting accounts are not supported. Keep Algo Trading OFF.
4. MT5 → File → Open Data Folder → MQL5 → Indicators. Create a folder named TradeLens. Copy MT5/JournalStudioTrades.ex5 into it (the .mq5 source is included for transparency; it is optional for installation). In Navigator → Indicators, right-click Refresh, expand TradeLens and attach JournalStudioTrades to one chart. Keep MT5 connected. Do not enable Algo Trading.
5. Python 3 is needed on the Mac. Check with python3 --version in Terminal. If missing, install Python 3 from https://www.python.org/downloads/macos/ before continuing. No pip packages are needed.
6. In Terminal, type cd followed by a space, drag the extracted TradeLens-Mac-Setup folder into Terminal and press Enter. Then run:

python3 run.py

This imports locally and previews counts only. Nothing is sent. If export discovery fails, use python3 run.py --export followed by the exact path to your MT5 Common/Files/studio-trades.json. The ordinary chart Data Folder and Terminal/Common/Files are different folders.

7. When ready to send your own demo trade history and balance metadata to your own hosted journal, run:

python3 run.py --send

Paste YOUR OWN device token at the hidden prompt and press Enter. It is not saved in this package or terminal command history. Expect “Upload accepted.” Then refresh the hosted Journal and choose MT5 trades.

8. Repeat the --send command when you want another update. Keep MT5 open; exports must be less than30seconds old. This version is manual one-shot upload, not continuous automatic sync.

The local cache is created on YOUR Mac at ~/Library/Application Support/TradeLensUploader/journal.sqlite3, with private file permissions. The local and hosted journals pin the first imported account. Do not copy Richard's cache or use his device token; do not mix MT5 accounts in one journal. If an account-change error appears, stop and request help rather than deleting records.

No live candle charts or AI reviews are uploaded in this release. Trade P/L is net as validated by the importer; partial closes are separate rows. Account balance is separate from the P/L ledger. Server-side device pairing is authenticated but not independent broker verification.

CHART UPDATE
Attach BTCStudioQuotes on a Bitcoin demo chart and GoldStudioQuotes on a Gold demo chart. Keep Algo Trading off.
For continuous journal and chart uploads run: python3 run.py --send --watch
Paste your own device token at the hidden prompt. Keep MT5 open and the Mac awake. Ctrl+C stops.
Missing indicators leave that instrument unavailable; stale data is labeled. No orders are sent.

TP/SL RECORD UPDATE
Reload JournalStudioTrades once after replacing its compiled file so open positions export their current Stop Loss and Take Profit. Keep Algo Trading off. The importer retains timestamped observations; exit-fill records describe levels at closing, not necessarily at entry. Missing fields stay unknown. No manual TP/SL entry or broker order is sent.

LIVE JOURNALING (explicit opt-in; no orders or SL/TP changes)
Supported accounts: USD, hedging, UTC+0 broker server. Netting and other currencies/offsets remain unsupported.
Use your own TradeLens login and token. A workspace already pinned to another MT5 account or account mode will reject this upload; use a separate TradeLens workspace to keep histories separate.
1. Replace JournalStudioTrades.mq5 and .ex5 with this bundle's versions.
2. Remove the old indicator, attach JournalStudioTrades to ONE chart, and set Inputs > AllowLiveJournal = true. Keep Algo Trading OFF.
3. Run: python3 run.py --send --watch --allow-live
The live cache is separate from the demo cache. Live exports keep demo=false. LIVE is labeled in the uploader and journal sync panel.
Only trades, current positions, balance and protective records are uploaded for live accounts. No chart feeds are included; existing quote indicators remain demo-only.
A hosted server update is required before live uploads are accepted. Never share upload tokens in chat.

PROVISIONAL ERRANTE RECENT MODE
For ErranteSC-Live (also ErrantesSC-Live), USD hedging accounts reporting UTC+2/+3:
python3 run.py --send --watch --allow-live --errante-recent
No indicator replacement is required beyond the live-enabled JournalStudioTrades included here. Set AllowLiveJournal=true and leave Algo Trading OFF.
A separate local live-errante-provisional cache is used. The initial import defers entire positions with entries older than seven days, even if their exit is recent. Future new positions can continue syncing. Original broker timestamps are retained in trade provenance and raw deal records. All accepted times remain PROVISIONAL because historical DST rules are unverified. Trades within two days of either US or EU potential switch dates are marked for review. This does NOT claim either calendar is the broker's actual rule.
If the observed broker offset changes, imports stop and previously imported timestamps remain unchanged; reconciliation is required. Do not delete caches to bypass this protection.
The hosted server update must be redeployed to preserve the provisional provenance and warnings. A workspace already pinned to another account or timezone mode rejects mixed uploads. Live chart feeds remain excluded.

HOSTED TRADE CHART REVIEWS (DEMO FEEDS ONLY)
After the server update is deployed, completed BTCUSDm/XAUUSDm M5/M15/H1 candles are retained under your own hosted journal. Keep the quote indicators and uploader running. Missing historical bars remain gaps; the server never invents them. The project uploader can additionally backfill a local broker_candles archive; a fresh standalone setup may only have the history in its current indicator exports.
Use Journal > Review trade to see entry/exit markers and recorded SL/TP price lines. Save review snapshot freezes the current chart data and trade markers. The display is historical reconstruction, not an entry-time screenshot or proof of execution. Live-account charts, including Errante, remain unsupported.
